# Content Pack IV — C0 Authority / Access Audit

> Scope: prepare the post-Ch35 Branch Sight discovery arc without creating a parallel progression system.
> Result: **GO for CP4-1 / Deep Green contradiction chain.**

## 1. Narrative prerequisite

Canonical prerequisite is Story Expansion II Ch35 final clear (`35-8`).

Why:
- Ch35 establishes coordinated observation.
- Ch35 leaves the first bounded impossible result at the Deep Green Forest coordinate.
- Branch Sight should therefore feel like investigation of a consequence the player already witnessed, not an unrelated optional portal.

No later Story chapter is required.

## 2. First Region

Use **深緑の森 / Ch2** as the first contradiction location.

Reasons:
- it is familiar and early enough that the player has a strong Prime-history reference.
- Ch35 already points specifically to this coordinate.
- the existing boss event supplies a clean historical divergence point: the Great Tree Spirit survived vs was defeated.
- a second authored history can plausibly express “the forest never formed” without changing Prime canon.

Prime remains authoritative for the player's original Story history.

## 3. Discovery ownership

Preferred authority:
- Story clear state for prerequisite context.
- existing Adventure / `world2.discoveries` for evidence discoveries and the awakening event.
- Rumor Notebook for NEXT guidance and contradiction setup.
- Codex / Chronicle for interpretation and persistent narrative record.

Do not create:
- `branchSightSave`,
- `multiverseProgress`,
- Branch XP,
- Branch currency,
- a second discovery registry.

Branch Sight should be represented by one explicit authored discovery/state inside existing ownership.

## 4. Deterministic access

The first awakening must be deterministic after authored prerequisites are satisfied.

Forbidden sole gates:
- Normal/Hard/Extreme or any difficulty clear,
- World Tier,
- player level,
- gear score,
- one mandatory Unique,
- companion/job/rune build,
- rare random event,
- daily/weekly schedule,
- token count.

Optional systems may add flavor or alternate clue wording only.

## 5. UI ownership

No new Home button.

Before Branch Sight:
- Region UI shows Prime only.
- Branch names/count are not rendered.

After Branch Sight + a specific Branch discovery:
- the existing Region context may expose a discovered historical overlap.
- only discovered anchors are visible.
- the total number of Branches stays unknown.

World Tier remains a difficulty/content modifier, not a visibility gate.

## 6. Story-language ladder

Before awakening:
1. observation mismatch,
2. impossible record,
3. incompatible history,
4. all records appear internally consistent.

At awakening:
- perception changes through the Parallax Core event.

After awakening:
- explicit “divergence” / Branch terminology may be introduced gradually.

Do not reveal before awakening:
- 王樹領,
- 深緑消失域,
- 観測分岐世界,
- Branch Sight as a menu/system label,
- Transcendents.

## 7. Combat / reward ownership

CP4 investigation does not require a new battle system or boss ladder.

If combat occurs:
- use existing BattleEngine/TextBattleScreen,
- use local transformed ecology/boundary instability,
- do not introduce a generic “multiverse guardian” rank.

Rewards remain under existing Gear/Unique/Option/Item Power authorities.

No:
- new rarity,
- fourth Option,
- Item Power cap change,
- Branch currency,
- mandatory perception gear.

## 8. Save compatibility

CP4 is additive:
- Ch1–35 stage clear IDs are untouched.
- Deep Green Forest Prime history remains playable.
- new evidence uses new discovery/event IDs.
- Branch Sight activation adds state rather than migrating existing Story clears.
- old saves that have cleared Ch35 may discover the CP4 chain normally.

## 9. Observed Branches boundary

Content Pack IV owns:
- contradictory-history investigation,
- Parallax Core contact,
- Branch Sight awakening,
- first recognized Branch anchor presentation.

`OBSERVED_BRANCHES_MULTIVERSE_ROADMAP.md` owns:
- full Branch data model,
- Branch Region traversal,
- divergence-specific ecology,
- technology profiles,
- Branch gear origin metadata,
- Walker/Transcendent encounters,
- later Branch clusters.

This boundary prevents CP4 from silently becoming a second multiverse implementation.

## 10. CP4-1 implementation target

Implement one complete deterministic chain in Deep Green Forest:

`post-Ch35 rumor → Prime evidence → impossible survival record → no-forest living-memory trace → overlap coordinate`

Stop before Branch Sight activation.

Acceptance:
- no explicit Branch terminology yet,
- no RNG mandatory step,
- no difficulty gate,
- no new top-level UI,
- Prime Story unchanged,
- clear NEXT guidance toward the overlap coordinate.

## Decision

**GO — CP4-1 / Deep Green contradiction chain.**
