# Blade Vale — Observed Branches: Branch Sight & Transcendent Observers

> Canonical supplement to `OBSERVED_BRANCHES_MULTIVERSE_ROADMAP.md`.
>
> Purpose: define **how the player becomes capable of perceiving Branch worlds** and establish a class of beings capable of observing multiple histories without reducing the setting to a simple difficulty unlock or a copy of ordinary gods.

## Core principle

Observed Branches are **not unlocked because the player cleared a harder stage**.

There is no progression such as:

```text
Normal clear
  ↓
Hard clear
  ↓
Extreme clear
  ↓
Multiverse unlocked
```

That would make the multiverse feel like a menu tier rather than a discovery about reality.

Instead:

```text
Prime Story / Ch31–35
  ↓
shared observation becomes possible
  ↓
contradictory history is discovered in a known Region
  ↓
player encounters a Branch-sensitive object / phenomenon
  ↓
contact changes what the player is capable of perceiving
  ↓
the same Region now contains an impossible historical overlap
  ↓
first Observed Branch becomes visible
```

The player does not become strong enough to enter another history.

**The player becomes capable of noticing that it was already there.**

---

# Branch Sight / 分岐視

Working term: **Branch Sight / 分岐視**.

This is not a character stat, skill tree, currency, level or permanent combat buff.

It is a narrative/perception state represented through existing Story / Discovery / Adventure state.

Before Branch Sight:
- contradictory records look corrupted,
- Branch echoes are interpreted as ordinary Boundary noise,
- impossible NPC memories are dismissed as inconsistency,
- Branch entrances are literally not presented in the Region UI.

After Branch Sight:
- the player can recognize two incompatible histories occupying the same observed location,
- certain Adventure scenes gain a new interpretation,
- discovered Branch anchors become visible inside the existing Region context,
- Codex / Chronicle can record historical divergence explicitly.

Branch Sight does **not** reveal all Branches.

It only allows the player to recognize Branch evidence when a specific Branch has been sufficiently observed.

---

# First awakening event

Recommended first canonical activation occurs **after Story Expansion II**, during Content Pack IV.

## The object / phenomenon

Working name:

**視差核 / Parallax Core**

Alternative names reserved for writing pass:
- 分岐観測片
- 二史核
- 観測残晶
- 不一致座標核

It should not simply be a magical key that says “multiverse unlocked”.

The object is found in a familiar Region after multiple records disagree about the same historical event.

Example sequence using 深緑の森:

```text
Rumor:
「森の大樹霊は討たれた」

Codex / old record:
「森の大樹霊は今も森を統治している」

Living-memory trace:
「そもそも森は存在しなかった」
```

At first these are impossible contradictions.

Investigation leads to a location where all three observations overlap.

The player touches / synchronizes with the Parallax Core.

### What happens

Do not immediately teleport the player.

Instead:
- sound doubles for one moment,
- familiar terrain appears in two incompatible states,
- an NPC silhouette exists and does not exist at once,
- a known path briefly becomes a living root corridor, then a blank Boundary scar,
- the interface returns to normal.

After returning to the Region screen, a previously impossible history can now be recognized.

```text
深緑の森

[通常史]
[観測分岐：王樹領]
```

The second Branch `深緑消失域` remains hidden until separately discovered.

This preserves mystery and prevents Branch Sight from becoming an “unlock every alternate map” switch.

---

# Access authority

Branch access should be derived from **explicit authored discoveries**, not difficulty completion.

Preferred authority:
- existing Story clear state for prerequisite narrative context,
- existing `world2.discoveries` / Adventure discovery for Branch evidence,
- one explicit Branch Sight awakening discovery/event,
- one explicit discovery/anchor per Branch.

Forbidden as sole gates:
- player level,
- World Tier rank,
- Normal/Hard/Extreme clear,
- random Rare Event,
- gear score,
- owning one mandatory Unique,
- daily/weekly schedule,
- arbitrary multiverse token count.

High difficulty may affect **what is inside** a Branch through existing World Tier and combat systems, but not whether reality itself becomes visible.

# Transcendent multiversal beings

Observed Branches introduces entities that can perceive more than one fixed history.

Working umbrella term:

**Transcendents / 超観測者**

Alternate in-world terms:
- 越境観測体
- 多史存在
- 外史者
- 高位観測者

These are not automatically gods and are not necessarily one species or faction.

A Transcendent is defined by capability:

> **It can maintain awareness across multiple observed histories without losing its identity when the histories disagree.**

MOTHER / ARCHITECT do not automatically qualify. They administer structures inside known world architecture and can themselves be observed.

The external civilization also does not automatically qualify.

---

# Three Transcendent archetypes

## 1. The Walker / 歩史者

Kang-like narrative role without copying Kang's identity or mechanics.

A being that can move between stable Branches and remembers outcomes that never happened in Prime.

Characteristics:
- speaks to the protagonist as if they have met before,
- may possess technology from several incompatible histories,
- treats Branches as strategic terrain,
- understands divergence points exceptionally well,
- is still a finite individual with motives, limits and possible mistakes.

Possible title:

**万路卿アステリオン / Asterion, Lord of Many Roads**

Placeholder only; final naming pass may replace it.

Narrative use:
- recurring rival / ally / manipulator,
- knows several possible futures but not every future,
- may deliberately preserve one Branch and sacrifice another,
- can introduce the terrifying idea that Prime is not necessarily the “main” world from anyone else's perspective.

Important limit:
- cannot freely rewrite history.
- can travel among sufficiently fixed Observed Branches, not arbitrary imaginary possibilities.

---

## 2. The Domain Being / 界喰級存在

Dormammu-like scale without copying Dormammu.

A being whose identity is inseparable from a vast realm or historical domain.

It does not merely travel to Branches.

**Its presence can occupy more than one Branch at once.**

Possible working concept:

**無窮界主・ヴァル＝ネア / Val-Near, Sovereign of the Unbounded Fold**

Characteristics:
- perceives ordinary worlds as local surfaces,
- communicates through environmental changes rather than normal dialogue,
- cannot necessarily fully manifest inside Prime due to Veil / observation constraints,
- may consume, merge or silence unstable Branches,
- is not automatically evil; its goals may be incomprehensible but internally consistent.

Use sparingly.

A Domain Being should feel qualitatively different from a large raid boss.

Its first appearance should probably be indirect:
- the same shadow in two Branches,
- identical damage appearing in incompatible histories,
- a sentence started by one NPC and finished by another version of that NPC,
- a region boundary bending toward the same impossible direction in multiple worlds.

---

## 3. The Archivist / 全史記録者

A more neutral or ambiguous Transcendent class.

It observes and preserves fixed histories rather than conquering them.

Possible working entity:

**記録者セプト / SEPT, the Archivist**

Characteristics:
- may know that histories disappear when no observation preserves them,
- refuses to answer questions whose answers would alter observation itself,
- can provide evidence that even Transcendents do not know the total number of Branches,
- useful for explaining rules without becoming an omniscient exposition machine.

Potential twist:
- what looks like one Archivist may actually be one identity distributed across several Branch instances.

---

# Transcendent rules

1. No omnipotent character.
2. No character knows every possible history.
3. Stable Observed Branches are finite/authored; Transcendents cannot summon infinite arbitrary universes.
4. Seeing multiple histories does not mean controlling them.
5. Prime cannot become meaningless because “another version always exists”.
6. Death, choices and consequences inside a Branch remain meaningful.
7. A Transcendent may have multiple manifestations, but duplicate versions must follow authored rules.
8. MOTHER / ARCHITECT remain administrator-level entities, below this new conceptual layer unless later canon deliberately changes their capabilities.
9. The external civilization remains distinct and may itself fear or study Transcendents.
10. Do not immediately establish a single supreme multiverse emperor.

---

# The protagonist's relationship to Transcendents

The protagonist should **not immediately become a Transcendent**.

Branch Sight is much smaller:

```text
ordinary person
  ↓
can perceive contradiction
  ↓
can recognize fixed Branches
  ↓
can traverse some Branch anchors
  ↓
???
```

This allows a long future growth arc.

A true Transcendent may notice the protagonist specifically because the protagonist can retain memory after crossing a Branch boundary.

That creates a good first-contact line concept:

> 「……お前、今のを覚えているのか。」

The scary part is not that the entity knows the multiverse exists.

The scary part is that **it did not expect the protagonist to remain the same person after seeing it.**

---

# First Transcendent encounter recommendation

Do not make the first Transcendent a boss fight.

Recommended sequence:

1. Branch Sight awakens.
2. Player explores 王樹領.
3. A distant unidentified traveler appears in both Prime and 王樹領.
4. Their clothing/equipment differs slightly, but one detail is identical.
5. They refer to a conversation that never occurred in Prime.
6. They notice the protagonist remembers crossing histories.
7. They leave without explanation.

Only later does Codex / Chronicle classify the phenomenon as an entity retaining identity across histories.

This makes the first Transcendent feel unsettling rather than just “next stronger enemy”.

# Transcendent equipment

Transcendent gear must not become a new rarity tier.

Instead, existing Gear authorities can represent artifacts assembled from incompatible technologies.

Examples:

### 多史機装・PARALLAX FRAME
Origin:
- multiple observed Branch technologies

Fixed identity:
- effect changes based on sequence/condition rather than raw permanent multiplier.

### 二史剣・CONTRADICTION
Origin:
- two Branch versions of one weapon reconstructed into one authored Unique

Fixed identity concept:
- alternates between two combat identities based on player state.

### 無界衣・OUTSIDE SKIN
Origin:
- Domain Being residue rather than civilization craft

Fixed identity concept:
- strong phase/mitigation identity with a meaningful condition or drawback.

Rules:
- no Transcendent rarity,
- no fourth random Option,
- no Item Power cap increase,
- no mandatory best-in-slot status,
- extremely rare authored identities should have narrative provenance.

# Roadmap integration

This supplement modifies the future Observed Branch implementation order conceptually.

## Story Expansion II / Ch31–35

Add only foreshadowing:
- impossible duplicated observation,
- one event apparently recorded from two incompatible histories,
- no explicit “multiverse” terminology,
- no Branch travel yet.

## Content Pack IV

Primary discovery arc:
- contradictory history chain,
- Parallax Core investigation,
- Branch Sight awakening,
- first explicit evidence that both records are real.

## Observed Branches M0–M3

M0 audit must additionally freeze:
- Branch Sight ownership,
- Branch discovery authority,
- Transcendent lore boundaries,
- no difficulty-tier access shortcut.

M1 branch data must support:
- authored `discoveryCondition`,
- `anchorDiscoveryId`,
- hidden-until-observed behavior,
- optional Transcendent evidence references.

M2 Branch discovery must implement the Parallax Core awakening path before any Branch selector appears.

M3 UI must not render Branch selection unless the specific history has been discovered.

## M4 / 王樹領

First traversable Branch.

Add the first indirect Walker-class encounter, but do not explain its full identity.

## M6 / 深緑消失域

The same Walker may appear with knowledge inconsistent with the 王樹領 encounter.

This proves their continuity across Branches.

## Future M13 — Transcendent Layer I

Only after multiple Branches are stable:
- formalize Transcendent classification,
- recurring Walker storyline,
- first Domain Being evidence,
- Codex/Chronicle multiversal entity records,
- no new top-level progression system.

## Future M14 — Cross-Branch Crisis

A later major arc may involve one event affecting multiple fixed Branches at once.

This is where Transcendents can become central actors.

Do not implement before ordinary Branch exploration has enough emotional weight.

---

# Acceptance contracts

Observed Branch access is correct only if:

- clearing a difficulty tier alone never reveals a Branch,
- first Branch discovery has a deterministic authored narrative path,
- the player experiences a perception-change event before Branch UI appears,
- undiscovered Branch count remains hidden,
- World Tier remains separate from Branch visibility,
- Transcendents are introduced as narrative entities, not a new power-level ladder,
- MOTHER / ARCHITECT and the external civilization retain their existing identities,
- Gear contracts remain max-three Options / Lv1–100 / current rarity and Item Power caps,
- no multiverse currency / stamina / daily portal / FOMO rotation is introduced.

## Intended player feeling

Before:

> 「別の世界があるらしい」

After Branch Sight:

> 「ずっと同じ場所を見ていたのに、俺には片方しか見えていなかった。」

After the first Transcendent encounter:

> 「こいつは別世界を知っているんじゃない。別世界でも“同じこいつ”なのか？」
