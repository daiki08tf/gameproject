# Blade Vale

スマホ向け・ステージクリア型のハック＆スラッシュRPG。ビルド不要、ブラウザで即プレイできます（Canvas2D + Vanilla JS ES Modules のみ、外部ライブラリ・画像・音声素材なし）。

## 遊び方

ES Modules を使っているため `file://` では動かせません。ローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 操作方法（スマホ・セミオート）

| 操作 | 内容 |
|---|---|
| 移動 | 画面左下の仮想スティック |
| 通常攻撃 | **自動**（射程内に敵がいれば自動で斬りかかる） |
| スキル | 右下のスキルボタン（クールダウン制・MP消費） |
| 必殺技 | 右下の必殺技ボタン（ダメージを与える/受けるとゲージが溜まる） |

## ゲームの特徴

- **ステージ/クエスト制**：拠点(ホーム)からステージを選んで出撃。全滅させればクリア。
- **死んでもリセットされない**：ステージ敗北してもレベル・職業・装備・所持金は一切失わない。撃破した分の経験値・ゴールド・ドロップは確定入手。初回クリア限定報酬のみクリアが必要。
- **装備システム**：武器/盾/頭/胴/アクセ×2の6スロット。「⚡最強装備」ボタンで所持品の中から自動で最強構成に一括変更。
- **職業システム（基本職→上級職→特級職→勇者）**：
  - 基本職 15種（Lv上限なし、Lv15でマスター、Lv10で転職可能）
  - 上級職 30種（基本職2つマスターで解放、Lv30でマスター、Lv20で転職可能）
  - 特級職 10種（上級職2つマスターで解放、Lv50でマスター、Lv30で転職可能）
  - 勇者（特級職を3つ以上マスターで解放）
  - レベル上限は撤廃済み。マスター基準を超えてもレベルは上げ続けられ、職業ランクが上がるほどステータス成長率も大きくなる。
- 進行データは `localStorage` に自動保存。

## 構成

```
index.html          画面構造（タイトル/拠点/ステージ選択/戦闘/リザルト/装備/職業）
css/style.css        UIスタイル（モバイル想定）
js/main.js           画面遷移ルーター・イベント配線
js/state.js          永続プレイヤーステート（localStorage保存・ステータス計算）
js/battle.js         戦闘エンジン（仮想スティック・自動攻撃・スキル・敵AI・描画）
js/joystick.js       仮想スティックコンポーネント
js/audio.js          効果音（Web Audio APIでその場生成）
js/data/jobs.js      職業データ（基本/上級/特級/勇者・成長率・解放条件）
js/data/equipment.js 装備データ・戦闘力スコア計算
js/data/enemies.js   敵データ
js/data/stages.js    ステージ/章データ
js/screens/*.js      各画面のレンダリング処理
```
