# Blade Vale

トップダウン視点のハック＆スラッシュ・サバイバルゲーム。ビルド不要、ブラウザで即プレイできます（HTML5 Canvas + Vanilla JavaScript のみ）。

## 遊び方

1. `index.html` をブラウザで直接開くか、ローカルサーバーで配信します。

   ```bash
   python3 -m http.server 8000
   # ブラウザで http://localhost:8000 を開く
   ```

2. 「ゲーム開始」を押してスタート。

### 操作方法

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` または矢印キー |
| 攻撃（マウス方向） | 左クリック（長押し可）または `Space` |

## ルール

- 四方から湧いてくる魔物を斬り倒して生き延びよう。
- 敵を倒すと XP オーブと（低確率で）回復ポーションをドロップする。
- XP を集めてレベルアップすると HP・攻撃力・移動速度が強化される。
- 時間経過でウェーブが進行し、敵の数・強さ・出現頻度が上昇する。
- HP が 0 になるとゲームオーバー。スコア・到達レベル・生存時間が表示される。

## 敵の種類

| 種類 | 特徴 |
|---|---|
| グラント（赤） | 標準的な近接敵 |
| ファスト（黄） | 低HP・高速で突っ込んでくる |
| タンク（紫） | 高HP・低速だが高ダメージ |

## 構成

```
index.html      画面構造・HUD・スタート/ゲームオーバー画面
css/style.css   見た目・UIスタイル
js/game.js      ゲームロジック一式（入力・物理・戦闘・描画・音声）
```

外部ライブラリ・画像・音声ファイルは一切使用していません。効果音は Web Audio API でその場生成しています。
