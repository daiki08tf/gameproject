# Loot 3.0 — Endgame Chase Rules

These labels are **not item rarities**. Base rarity still ends at Mythic. Ancient remains the highest Affix rarity.

## Completion labels
- `ENDGAME PIECE`: IP7000+ with a meaningful combination of high-end roll signals.
- `APEX DROP`: IP8500+ with several stacked endgame-quality signals.
- `GOD ROLL`: IP9500+ and a true combined jackpot: Ancient Affix + (Build Affix or Legendary Power) + at least one Greater Affix.

Raw Item Power by itself can never create a GOD ROLL.

The purpose is to give endgame farming a visible finish line while preserving the existing Equipment 3.0 rarity/Affix model.
